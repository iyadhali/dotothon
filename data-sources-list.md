# Data Sources List

| Category | Source | Purpose | Notes |
| :-- | :-- | :-- | :-- |
| Government Data | Maldives Bureau of Statistics (MBS) - Census 2022, Datathon Datasets | Population, islands, migration, and demographic data | Core baseline for analysis. |
| Transport (Sea) | RTL / MTCC | Ferry timetables, routes, and bus data in Greater Malé | Used for inter-island sea connectivity. |
| Transport (Air) | MACL | Airport data and air connectivity | International/domestic airport information. |
| Transport (Land) | FollowMe, Avas Ride | Ride-hailing and land transport data | Greater Malé only. Private transport has no public route data. |
| Research Baseline | HeiGIT/OpenAccessLens (HDX) | Car-only accessibility baseline | Used for comparison and key statistics. |
| Geospatial | OpenStreetMap | Map data and spatial reference | Utilized, no tiles used for offline capability. |
| Health | Ministry of Health (MHS 2020), Aasandha | Health facility data, bed capacity, and evacuation records | Used for healthcare access analysis. |
| Education | Ministry of Education (MoE School Directory 2023), MBS | School locations, grades, and enrolment/migration data | Used for education access analysis. |
