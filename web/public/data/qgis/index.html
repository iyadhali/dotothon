Maldives multimodal QGIS export

EPSG:4326. Facilities and access links are island-level, not building coordinates. Ferry records are one reference day, not a full calendar; air frequencies are estimated.

  • islands.geojson — 200 node islands (inhabited + airport-only)
  • facilities.geojson — 945 facilities (501 source + 444 intervention layer)
  • ferry_routes.geojson — 102 recorded RTL trips
  • air_routes.geojson — 31 operating domestic airport pairs
  • access_edges.geojson — 153 access/link edges
  • access_style.qml — categorized line style by mode
  • README.md — QGIS and Mapbox workflow
